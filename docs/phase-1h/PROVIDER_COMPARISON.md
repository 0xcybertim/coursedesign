# Phase 1H-A subject-mask provider comparison

Date: 2026-07-22  
Scope: a completed bounded raster subject-mask sandbox benchmark only

## Recommendation

Photoroom was selected for the bounded benchmark because the dedicated endpoint accepts a direct multipart upload, can return the grayscale segmentation mask itself with `channels=alpha`, exposes an uncertainty score, has fixed public regular-tier pricing of **$0.02 per call**, and is straightforward to call from server-side JavaScript without a new runtime or production service.

Tim approved the exact contract and the run completed once using the free sandbox key. All 29 outputs contained the documented sandbox watermark, so Photoroom sandbox is **not recommended as vectorization input** even though the binary evaluator's geometry metrics passed. The benchmark adapter remains isolated under `tools/phase-1h`; nothing is connected to the application route or interface.

Tim selected remove.bg for the no-watermark free follow-up on 2026-07-22. Its separately authorized run is now complete: 20/20 clean masks passed, all 9 unsafe cases rejected, all returned masks passed mandatory visual inspection, exactly 29 calls were made with zero retries, and the cost was $0. `REMOVE_BG_PROVIDER_SETUP.md` and `REMOVE_BG_BENCHMARK_REPORT.md` contain the current decision.

## Bounded run authorization consumed

- Provider: Photoroom Remove Background API, `channels=alpha`, PNG response.
- Fixtures leaving the machine: exactly **29 generated 480 × 480 PNGs** from `tests/fixtures/phase-1h/input/`; no user images, Phase 1G concepts, prompts, metadata, people, logos, or scraped media.
- Cases: exactly **20 clean**, **3 empty**, **3 multi-subject**, and **3 badly occluded**.
- External calls: exactly **29 maximum**, one attempt per fixture.
- Retries: **0**.
- Maximum authorized provider cost: **$0.58**. The supplied sandbox key made the expected actual charge **$0.00**; the full 29-call authorization is nevertheless consumed.
- Expected latency: current provider service time is about 0.28 s median / 0.55 s p90; allow roughly **30–90 seconds end to end** for the sequential run. Each call has a hard 30 s timeout and is never retried.
- Durable evidence: fixture/input hashes, returned-mask hashes, byte counts, redacted request IDs, HTTP status, uncertainty, latency, objective metrics, and pass/fail only. No API key, authorization header, base64, or user/source image is written to JSON.
